# 🎓 Students Assistant AI

**Your Complete Academic Life, Organized in One Intelligent Platform.**

A comprehensive full-stack web application that helps students manage their academics, attendance, fees, notes, assignments, projects, exams, CGPA, resume, and get AI-powered study assistance.

## ✨ Features

- 📚 **Academic Management** - Track subjects, marks, and grades
- 📋 **Attendance Tracking** - Subject-wise with smart warnings
- 💰 **Fee Management** - Track payments and balances
- 📝 **Notes Library** - Organize by subject/unit with file uploads
- ✅ **Assignment Tracker** - Status tracking with deadlines
- 🚀 **Project Portfolio** - Showcase your projects
- 📊 **Exam Analytics** - Charts and performance insights
- 🧮 **CGPA Calculator** - GPA and CGPA with progression graphs
- 📄 **AI Resume Builder** - Generate professional resumes
- 🤖 **EduAI Chatbot** - AI-powered study assistant
- 📖 **Study Material Generator** - AI-generated notes and flashcards
- ❓ **Important Questions** - AI-predicted likely exam questions
- 📅 **Study Planner** - AI-generated personalized schedules
- 🔍 **Global Search** - Search across all your data
- 🌓 **Dark Mode** - Beautiful light/dark themes
- 📱 **Fully Responsive** - Works on all devices

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, Chart.js, Font Awesome
- **Backend**: Python 3, Flask
- **Database**: SQLite with SQLAlchemy ORM
- **AI**: OpenAI-compatible API (configurable)
